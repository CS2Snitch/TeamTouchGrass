Palworld

COMMUNITY SERVER

Server address

play.teamtouchgrass.com:45000

Enter the complete address, including :45000, inside Palworld. This is a game address, so opening it in your web browser won’t join the server.

How to join

  1. Open Palworld and select Join Multiplayer Game.
  2. Paste the address into the box below the server list and select Connect.
  3. If prompted, use the server join password. Ask in Discord if you need access.
Address not connecting?

Try the direct IP if the domain hasn’t updated yet or your game client won’t accept it.

15.204.102.13:45000

If you don’t see a direct connection box, or neither address works, ask for help in Discord and include your platform and error message.

Server availability isn’t monitored on this page. Other game sessions are organized in Discord. Official Palworld connection guide ↗
